# 溟岚问道

单机网页版**水墨国风修仙放置养成游戏**。纯前端，无服务器，存档保存在浏览器 localStorage。

- 技术栈：Vite + 原生 JavaScript + Canvas / DOM / SVG + WebAudio
- 运行时零依赖；所有美术与音效均为程序化生成（见 [CREDITS.md](CREDITS.md)）
- 世界观与名称全部原创（见 [LORE.md](LORE.md)）

## 运行

需要 Node.js 18 或更高版本（开发时使用 22）。

```bash
npm install
```

```bash
npm run dev
```

打开终端里显示的地址（默认 http://localhost:5173）。

构建静态文件：产物在 `dist/`，可以部署到任意静态服务器，或者用 `npm run preview` 本地预览。

```bash
npm run build
```

## 测试

```bash
npm test
```

包括三组：
- `tests/engine/`：引擎单元测试。
- `tests/data/`：数据校验，包括字段、数值范围、引用完整性和最低数量。
- `tests/simulation/`：整体模拟。500 个角色用固定种子从开局玩到金丹，同时做覆盖率检查、离线收益与存档的边界测试。

可以单独运行：

```bash
npm run test:engine
```

```bash
npm run test:data
```

```bash
npm run test:sim
```

浏览器端到端测试：先构建，再用预装的 Playwright 和 Chromium 走查全部 UI 流程。

```bash
npm run test:e2e
```

## 玩法

| 系统 | 说明 |
|---|---|
| 修炼 | 灵气随时间自动积累，离线也会累积，最多 8 小时，效率 80%。灵气满后点击「破关」突破小境界 |
| 境界 | 炼气 → 筑基 → 金丹 → 元婴 → 化神，每个大境界分前、中、后三期 |
| 渡劫 | 大境界之间要渡雷劫，多道天雷依次判定。可以服用护脉丹、固基丹减伤，携带回春丹回血，法宝也能减伤 |
| 灵根 | 开局随机，金木水火土，一到五个灵根不等。灵根越纯，修炼越快；功法元素与灵根相符时效果更强 |
| 功法 | 15 部：心法提升修炼速度，术法用于战斗，护体提升属性。可以装备和升级，有五行相克 |
| 炼丹 | 用秘境和药园产出的 12 种药材，按丹方炼制 8 种丹药。有成功率，分下品到极品四档品质 |
| 历练 | 5 个秘境，每趟 5 步：战斗、奇遇、陷阱、采药，最后一步是首领战。产出灵石、药材、法宝和功法 |
| 战斗 | 回合制自动战斗，玩家只需配置技能顺序和自动服药规则 |
| 结局 | 飞升上穹、寿尽坐化、劫火陨落三种。结局后可以「转世重修」，下一世带传承加成 |

从开局到金丹，普通节奏约 1.5 小时游戏时间。挂机和离线都计入。

## 设置

- **特效档位**：低、中（默认）、高。帧率连续 3 秒低于 40 时自动降一档。
- **音量与静音**：音频在第一次点击页面后才启动。
- **存档**：每 30 秒以及切到后台时自动存档。也可以导出或导入存档字符串。
- **重置**：清除存档和传承。

## 目录

```
src/core/      引擎：境界、修炼、离线、秘境、炼丹、渡劫、结局、Game 外观
src/combat/    属性、五行克制、回合战斗
src/save/      存档序列化、校验、迁移
src/data/      全部游戏数据与文本
src/ui/        界面与主循环（入口 src/ui/main.js）
src/art/       水墨程序化美术与特效
src/audio/     WebAudio 合成音效
styles/        样式
tests/         engine / data / simulation / e2e
```
